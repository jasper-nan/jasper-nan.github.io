Omamail 隐私权政策 / Privacy Policy

最后更新 / Last updated: 2026-09-22

1. 应用概述 / Overview

Omamail 是一款供本站作者（以下简称"用户"）个人使用的桌面邮件与日历客户端。它不是面向公众分发的服务，不运营任何服务器，不提供任何在线账户体系。本政策说明该应用如何访问、使用和存储数据。

Omamail is a personal-use desktop email and calendar client for the owner of this site. It is not a public service, operates no servers, and offers no online accounts. This policy explains how the app accesses, uses, and stores data.

2. 收集与访问的数据 / Data accessed

应用仅访问用户主动配置的邮箱账户中的以下数据：

  • 邮件内容与元数据：邮件正文、主题、发件人/收件人、时间戳、附件，用于显示、搜索、撰写与回复；
  • 日历数据（如启用）：日历事件与会议邀请，用于显示和应答；
  • 账户凭据：OAuth 令牌或应用专用密码，仅用于连接用户自己的邮件服务。

The app only accesses data in the mailboxes the user configures: message bodies, metadata and attachments; calendar events when enabled; and the OAuth tokens or app passwords used to connect to the user's own mail providers.

3. 数据的使用目的 / Purpose of use

所有数据仅用于：在本地显示用户的邮件与日历、执行用户主动发起的操作（发送、回复、归档、搜索、标记等）。应用不进行任何自动化分析、用户画像或行为追踪。

Data is used solely to display the user's mail and calendar locally and to perform actions the user initiates (send, reply, archive, search, label). No automated profiling or behaviour tracking occurs.

4. 数据存储与位置 / Storage and location

  • 邮件缓存仅存储在用户本机磁盘（~/.cache/omamail）；
  • 账户凭据与 OAuth 令牌仅存储在操作系统密钥串（Linux Secret Service / 系统 keyring）；
  • 应用配置仅存储在用户本机（~/.config/omamail）。

Mail caches live only on the user's own disk; credentials are stored only in the operating system keyring; configuration lives only on the local machine.

5. 数据共享 / Sharing

应用不向任何第三方出售、出租或共享数据，不包含分析组件、广告 SDK 或追踪器。邮件数据的唯一接收方是用户自行选择的邮件服务商（如 Gmail、Outlook），且仅在执行用户请求的操作（如发送邮件）时传输。

The app sells or shares no data with third parties and contains no analytics, advertising, or tracking components. The only recipients of mail data are the mail providers the user configures, and only to perform user-requested actions such as sending.

6. 数据安全 / Security

所有网络连接均通过 TLS 加密；凭据不以明文落盘；远程图片在邮件中默认被屏蔽，除非用户主动选择加载。

All network connections use TLS; credentials are never written to disk in plain text; remote images are blocked by default until the user chooses to load them.

7. 数据保留与删除 / Retention and deletion

本地缓存与凭据保留至用户退出账户或卸载应用为止。用户可随时：在邮件服务商处撤销 OAuth 授权；在应用内退出登录以清除令牌；删除本机目录（~/.cache/omamail、~/.config/omamail）以清除全部本地数据。

Local data is retained until the user signs out or removes the app. The user may revoke OAuth grants at the provider, sign out in-app to clear tokens, or delete the local directories to remove all local data.

8. 第三方服务 / Third-party services

应用本身不集成任何第三方服务。邮件数据在传输中经过用户选择的邮件服务商（Google、Microsoft 等），这些服务商各自适用其隐私政策。

The app integrates no third-party services itself. Mail data in transit passes through the providers the user chooses (Google, Microsoft, etc.), each governed by their own policies.

9. 用户权利 / Your rights

由于应用完全在本地运行且不收集任何数据，用户对自身数据拥有完全控制权：可随时查看、导出、删除本机上的全部数据，并可在服务商侧撤销访问授权。

Because the app runs entirely locally and collects nothing, the user retains full control: all local data can be inspected, exported, or deleted at any time, and access can be revoked at the provider.
