我用 AI 给 Linux 手搓了 11 套原神主题，全部开源

找不到现成的原神 Linux 主题，索性让 AI 从零造了一套：11 位角色、43 张 4K 壁纸、透明栏可读性实测达标。已开源到 GitHub，一键安装。

Tuesday, September 22, 2026

起因很简单：想给我的 Omarchy 换套原神主题，翻遍系统发现一套都没有。那就自己造——AI 负责干活，我负责挑毛病。最终成果：11 位角色、43 张 4K 壁纸，全部开源。

安装只需三行：

git clone https://github.com/jasper-nan/omarchy-genshin-themes.git
cd omarchy-genshin-themes && ./install.sh
omarchy theme set "Hu Tao"

换壁纸：omarchy theme bg next 循环，每个主题备了 4-5 张。

二、一套主题是怎么"炼"出来的

Omarchy 的主题本质上就是一个目录：一个 colors.toml 调色板 + 若干壁纸。 终端、状态栏、btop、浏览器的配色全部由系统从调色板自动生成——你只需要把颜色和壁纸做对。

但"做对"两个字，藏着不少工程细节。

1. 配色不是随便选的

每个角色的调色板从角色意象派生：主色提亮做 accent，压到明度 4-8% 做背景（保有色相，不是纯黑），明度 85%+ 做文字。18 个语义色全部同源，所以终端里红绿黄蓝看起来是"一套的"。

2. 壁纸的三条路线

  • Wallhaven 社区壁纸：公开 API 直接筛 3840×2160，按收藏数排序当质量代理（夜兰那张 938 收藏）
  • 官方祈愿立绘合成：从 Genshin 官方 Wiki 拉立绘，用"模糊延展"技法合成 4K——立绘自身模糊铺满做底色，中央原生立绘羽化融入，边缘色彩来自立绘本身，过渡自然
  • 搜图神器：逆向了它的前端签名协议（MD5 签名 + 时间戳头），登录会员账号搜真 4K

第一版合成用的是"渐变底 + 矩形羽化"，边缘很怪，被我一票否决重写——AI 干活，人来把关，这个组合很关键。

3. 一个没人注意过的细节：透明栏可读性

我的状态栏是透明的，文字直接压在壁纸上。第一版雷电将军主题顶栏文字完全看不清——立绘顶部是亮紫色天空，浅色文字糊成一片。

Omarchy 其实有自适应机制：透明栏时会采样壁纸顶部 26px 色带，在前景/背景色里选对比度更高的一个。问题出在立绘顶部是中等亮度紫——两个选项都不够对比。

解法：每张壁纸顶部叠加 260px 的主题底色渐变暗带（底部 150px），采样永远命中深色区。最后全库 43 张壁纸实测对比度 4.7 ~ 15.3:1（WCAG AA 标准是 4.5:1），张张达标。

三、顺手沉淀了一套工具

整个过程沉淀成一个可复用的 skill（技能包），放在我的私有 Gitea 上： 立绘抓取、搜图神器协议客户端、4K 合成脚本、对比度验证脚本，外加一份配色方法论和 11 套实测调色板。

以后再想做什么主题——别的游戏、别的角色、别的 IP——都是一句话的事： “帮我做个 XX 主题”，流水线自动跑。
