> 很多人对 Linux 桌面的印象还停留在"折腾驱动、配置劝退"。但 Omarchy 是另一个物种：装完即用、开箱即美，还能把 AI Agent 请进系统里当管家。这篇聊聊它凭什么成了我的主力机。

* * *

## 一、Omarchy 是什么

一句话：**Arch Linux（滚动更新）+ Hyprland（平铺窗口管理器）+ 一套审美在线的默认配置**。

它不是让你从零搭积木的发行版，而是把窗口管理、状态栏、终端、字体、主题全部调校好——装完就是一个能直接干活的桌面。背后的哲学：

  * **键盘优先**：窗口操作、启动应用、系统设置全靠快捷键，手不离开键盘
  * **平铺窗口**：窗口自动排列，永不互相遮挡，屏幕空间利用率拉满
  * **配置即文本**：所有配置都是文本文件，可备份、可版本管理、可一键恢复

* * *

## 二、效率：键盘流的快乐

平铺窗口用上就回不去。四个窗口自动四分屏，写代码左边是编辑器右边是终端，查文档浏览器自动占半屏——**不需要任何手动拖拽**。

Omarchy 还把所有常用操作统一成了 `omarchy` 命令族：

```bash
omarchy theme set "Tokyo Night"   # 一键换主题（全应用联动）
omarchy toggle nightlight         # 夜灯开关
omarchy capture screenshot        # 截图
omarchy reminder 15 "取快递"       # 15 分钟后提醒
omarchy pkg add docker            # 装软件
```

不用记散落在各处的配置项，一条 CLI 全搞定。配合 `SUPER+空格` 的启动器菜单，鼠标基本可以退休了。

* * *

## 三、优雅：一切皆可插件

Omarchy 的状态栏基于 Quickshell，**每个模块都是一个插件**。我自己的栏上跑着：天气、双格式时钟、键盘布局、系统更新提醒、托盘……还有两个自己写的：

  * **omastonk**：A 股指数实时行情插件（盯盘不用开网页了）
  * **omamail**：邮件状态指示

插件不喜欢默认的？`omarchy plugin clone omarchy.clock` 克隆一份改成自己的样式，热重载即改即看。想在换主题时自动跑个脚本？hooks 机制一行命令挂载。**这种"系统把扩展点都留好"的感觉，才是真正的优雅。**

* * *

## 四、美丽：4K 桌面 × 主题宇宙

Omarchy 自带 25 套官方主题（Catppuccin、Tokyo Night、Gruvbox、Rose Pine……），换主题是全局联动的：窗口边框、终端、状态栏、btop、编辑器配色一键同步。

我自己又加了 11 套原神主题（[已开源](https://github.com/jasper-nan/omarchy-genshin-themes)），配上 4K@2x 的显示器，每天换壁纸看角色立绘是真实的快乐：

![主题预览](/images/showcase/genshin-grid.jpg)

透明状态栏、毛玻璃模糊、圆角阴影、动态壁纸过渡——这些在 Omarchy 上全是默认开好的，不需要你写一行配置。

* * *

## 五、AI 赋能：把 Agent 请进系统

这是最让我觉得"未来已来"的部分。我的系统里常驻着 AI Agent，它不是聊天框里的问答玩具，而是**真正能干活的系统管理员**。

就用这篇文章开头的原神主题举例——整个生产过程 AI 包办了：

  * 翻遍系统确认没有现成主题
  * 逆向第三方图站的签名协议、登录会员账号搜 4K 图
  * 从官方 Wiki 抓角色立绘，ImageMagick 合成 3840×2160 壁纸
  * 发现透明栏文字看不清，自己定位到 Omarchy 的采样机制，给 43 张壁纸逐张验证对比度
  * 把整套流程沉淀成可复用的 skill，推到私有 Gitea；把主题成品开源到 GitHub
  * 顺手给博客写了这篇文章（对，就是你现在读的这篇）

我做的事情只有三件：**提需求、挑毛病、点确认**。

除了做主题，AI 还会帮我修 Hyprland 配置、诊断崩溃的进程（自动读 core dump 出报告）、管理 dotfiles。Linux 的门槛过去在于"什么都得自己查文档"，现在 Agent 把文档查了、把命令敲了、把坑踩了——**Linux 前所未有的亲民**。

效率、优雅、美丽、AI 赋能——四年前我很难想象这四个词能同时用来形容一个 Linux 桌面。现在它就在我屏幕上跑着，4K 分辨率，胡桃的壁纸，状态栏上 A 股指数在跳。

挺好的。
